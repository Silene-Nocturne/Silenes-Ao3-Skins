Welcome to Silene's Ao3 Skins

The skin coding are from bounckery on Tumblr [ https://www.tumblr.com/archivalcordial ]

All assets are either from Pinterest or tagged below by skin.

Each skin has either a mobile or a laptop/tablet version, depending on what you read on. 

HOW TO USE: Go to AO3 > Account > Dashboard > Skins Click on “Create site skin”. Set as site skin Copy the CSS code in GitHub or docs and paste it into the CSS text box. Click ‘Submit’.

Please Enjoy!
